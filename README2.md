🧠 Memora — Система интервального повторения
Memora — это высокотехнологичное веб-приложение для эффективного запоминания информации. В основе проекта лежит научно обоснованный алгоритм SM-2 (SuperMemo-2), который адаптирует график повторений под индивидуальную скорость забывания пользователя.

✨ Особенности интерфейса (Modern Soft UI)
Мы полностью переработали фронтенд, отойдя от стандартных "плоских" интерфейсов в сторону Soft UI:

Тактильный дизайн: Использование глубоких скруглений (rounded-[2.5rem]) и мягких многослойных теней.

Микро-взаимодействия: Динамические трансформации карточек режимов и анимированные иконки.

Адаптивные фильтры: Умная панель поиска и фильтрации с системой быстрых тегов.

Реверсивный режим: Уникальная возможность учить карточки "задом наперед" (ответ → вопрос) одним переключателем, что идеально для изучения языков.

🚀 Функциональные возможности
1. Режимы обучения
Приложение предлагает 4 различных сценария работы с колодой:

Обучение (SM-2): Основной режим. Алгоритм вычисляет дату следующего показа на основе ваших оценок.

Тренировка: Свободный просмотр всех карточек без влияния на статистику и интервалы.

Подбор пар: Игровой режим на сопоставление терминов и определений.

Тест: Классический квиз с вариантами ответов для проверки готовности к экзамену.

2. Учебный питомец и Геймификация
Чтобы поддерживать мотивацию, в систему встроен виртуальный питомец:

За каждую пройденную сессию начисляется опыт (XP).

Уровни питомца отражают ваш реальный прогресс в обучении.

Система Streak: Отслеживание серии дней без пропусков занятий.

3. Аналитика и планирование
Deck Stats: Мгновенный срез состояния колоды (сколько новых, сколько нужно повторить сегодня).

Календарь нагрузки: Визуализация предстоящих повторений на ближайшие недели.

🛠 Технический стек
Backend (/back)
Python 3.10+ / Django 4.2

Django REST Framework: Мощное API с поддержкой CRUD и кастомных экшенов.

JWT Auth: Безопасная авторизация с механизмом бесшовного обновления токенов.

SM-2 Engine: Собственная реализация алгоритма интервальных повторений.

Frontend (/front)
React 18 / Vite: Быстрая сборка и высокая производительность.

Tailwind CSS: Современная верстка с использованием кастомных конфигураций для Soft UI.

Lucide React: Единообразный сет системных иконок.

Axios: Централизованный клиент с интерцепторами для обработки токенов и ошибок.

🚦 Быстрый старт
Развертывание Backend
Склонируйте репозиторий.

Создайте виртуальное окружение: python -m venv venv.

Установите зависимости: pip install -r requirements.txt.

Выполните миграции: python manage.py migrate.

Запустите сервер: python manage.py runserver.

Развертывание Frontend
Перейдите в папку front/.

Установите зависимости: npm install.

Запустите проект: npm run dev.

📈 Алгоритм SM-2
Приложение использует модифицированный алгоритм SuperMemo-2.

График повторений строится таким образом, чтобы карточка предъявлялась пользователю в тот момент, когда вероятность её забывания становится критической. Это позволяет тратить минимум времени на повторение уже выученного материала.
